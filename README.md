# Ball Bash

A 2D puzzle game where you play as a basketball and have to reach the finish tile in each level.

![gif1](https://github.com/bengold105/Ball-Bash/blob/master/gifs/ballbash1.gif)

## Obstacles

The levels contain multiple types of tiles that could either help or hinder your path to finishing the level.
